# Projects

A **project** is the top-level container in IR-Board: every functionality, requirement, stakeholder, and document belongs to exactly one project, and access to those entities is ultimately scoped through it.

- **[Creating a Project](creating-a-project.md)** — starting a new project and choosing a priority style for its requirements.
- **[Functionalities](functionalities.md)** — grouping requirements into functional areas within a project.
- **[Project Lifecycle](project-lifecycle.md)** — the states a project moves through, and what each one means for its contents.

For how requirements themselves work once a project and its functionalities exist, see [Requirements](../requirements/index.md).
