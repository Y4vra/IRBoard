# User Guide

This guide covers day-to-day use of IR-Board: signing in, organizing projects, managing requirements, and collaborating with other users.

- **[Getting Started](getting-started.md)** — signing in for the first time and a tour of the navigation bar.
- **[Projects](projects/)** — creating projects and functionalities, and managing their lifecycle (active, deactivated, removed).
- **[Requirements](requirements/)** — creating, nesting, linking, reordering, and approving functional and non-functional requirements.
- **[Stakeholders](stakeholders.md)** — tracking the people and organizations with an interest in a project, and linking them to the requirements that concern them.
- **[Documents](documents.md)** — uploading supporting material and linking it to requirements for traceability.
- **[Access Control](access-control.md)** — how roles and permissions work in practice, and what each role can and can't do.

## Who this is for

This guide assumes you already have an account (an administrator invites new users — see [Access Control](access-control.md)) and are working within a browser. If you're setting up an instance of IR-Board rather than using one, see [Deployment](../deployment/index.md).
